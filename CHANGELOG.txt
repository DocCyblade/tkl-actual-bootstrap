WHAT’S NEW — v0.23.2
-----------------------
- General
  - Documentation migrated to simple plain text (.txt) across the repo.
  - Release packaging: exclude .git, node_modules, .DS_Store from bundles.

- bootstrap.sh
  - Installs "actualctl" by default (removed --install-ctl); still honors --ctl-path override.
  - --domain must be paired with --yes (live) or --dry-run (preview); if omitted, bootstrap prompts.
  - Systemd units hardened; graceful stop (SIGINT) and TimeoutStopSec=15.
  - Uses configs/config.json.tpl as seed source (falls back to inline JSON if template missing).
  - Nginx health endpoints: /healthz (edge) and /health/upstream (proxy to backend).

- actualctl
  - list shows only real version directories under /srv/app (v*), hides symlinks/npm artifacts.
  - Help/usage banners synced with docs; readable header blocks.
