WHAT’S NEW — v1.0.0-rc1
-----------------------
- Versioning & compatibility
  - Package set to **v1.0.0-rc1**; compat **>=v1.0.0-rc1 <v1.1.0**.
- CLI
  - New `actualctl prune-versions` to remove unused `/srv/app/v*` directories (not targeted by any instance link).
    Supports `--dry-run`, `--keep N`, and `--older-than DAYS`.
- Installer safety
  - `bootstrap.sh` validates `--install-version` via npm preflight, and performs atomic installs via a temp build dir (no leftovers on failure).
- UX
  - Banners default to ASCII lines; opt-in UTF‑8 via `USE_UTF8_BANNER=1` (still respects `NO_COLOR` and only applies on a TTY).
- Completions/docs
  - Bash completions installed to `/etc/bash_completion.d/` for both `actualctl` and `bootstrap.sh`.
  - Plain-text docs installed to `/usr/share/tkl-actual-bootstrap/docs/`.
- Defaults
  - Default Actual Sync Server remains **v25.7.1**.

WHAT’S NEW — v0.25.0
-----------------------
- Update/refresh workflow
  - New `--update-install` to refresh the installed assets (**VERSION**, **docs**, **actualctl**) without touching the app version/links.
  - Optional `--with-units`, `--with-nginx`, and convenience `--update-install-all` to also reinstall systemd units and re-render Nginx vhosts.
- Bash completions
  - New `completions/actualctl.bash` and `completions/bootstrap.bash`.
  - Installer copies them to `/etc/bash_completion.d/` (prints a hint to reload bash-completion).
- Docs
  - README now includes **Installation (fresh TurnKey Linux NodeJS)** and **Updating installed files (CLI/DOCS/UNITS/NGINX)**.
  - Plain‑text docs under `docs/` are installed to `/usr/share/tkl-actual-bootstrap/docs/`; `actualctl --help` points to `README.actualctl.txt`.
- Hardening & polish
  - Broad `set -u` safety: initialize locals, validate args, nounset‑safe traps; clearer errors.
  - Adaptive banners (auto width, ASCII fallback, TTY‑only bold, honors `NO_COLOR`) in both scripts.
  - Banners now default to ASCII; opt-in UTF-8 line via USE_UTF8_BANNER=1 (still respects NO_COLOR and only applies when on a TTY).
  - `actualctl` **and** `bootstrap.sh` prefer the system manifest `/usr/share/tkl-actual-bootstrap/VERSION` over a local `./VERSION`.
  - Installer safety: preflight npm version check for --install-version; atomic install via temp build dir (no leftover dirs on failure).
- Defaults
  - Default Actual Sync Server remains **v25.7.1** (examples updated accordingly).
- Not included
  - No `open` subcommand in this release.

WHAT’S NEW — v0.24.1
-----------------------
- CLI & Flags
  - bootstrap.sh: **--install-version <vX.Y.Z>** replaces `--version <ver>` to choose the Actual Sync Server version.
  - `--version` (no arg) now prints **script <Script-Version> (package <PKG_VERSION>)** in both scripts.

- Dynamic versioning
  - Both scripts resolve the package version from ENV/`./VERSION`/`/usr/share/tkl-actual-bootstrap/VERSION`/git tag, with header fallback.
  - Banners now show both **script** and **package** versions.

- Doctor remediation
  - `actualctl doctor --fix` installs/refreshes the system package manifest at `/usr/share/tkl-actual-bootstrap/VERSION`.

- Packaging
  - `bootstrap.sh` installs the package `VERSION` manifest to `/usr/share/tkl-actual-bootstrap/VERSION`.

- Docs/headers
  - Synchronized headers across README, scripts, systemd, and nginx templates; standardized Packaged-In/Compat where applicable.
  - Plain‑text docs are canonical (`*.txt`).

- Notes
  - **Breaking change:** `--version <ver>` removed from `bootstrap.sh`; use `--install-version <ver>`.
  - See per-script history below for details.
