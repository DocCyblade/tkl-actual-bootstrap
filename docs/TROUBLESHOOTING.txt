Troubleshooting
==========================

Quick checks
------------
- ./scripts/bootstrap.sh --version   (prints script/package versions)
- actualctl --version                (prints script/package versions)
- actualctl doctor                   (services, ports, nginx -t, upstream)
- actualctl doctor --fix             (also installs/refreshes package VERSION manifest)

502 Bad Gateway
---------------
- actualctl health <instance>
- systemctl status <instance>-budgetapp
- journalctl -u <instance>-budgetapp -n 200 -f
- nginx -t && systemctl reload nginx
- Check that /srv/<instance>/data/config.json port matches Nginx upstream
- Ensure systemd service is running

npm EACCES / cache issues
-------------------------
- Ensure:
    ls -ld /home/budget-server /home/budget-server/.npm
    chown -R budget-server:budget-server /home/budget-server
- Installs run as "budget-server" (runuser; fallback su)

Wrong domain / DNS
------------------
- Check /etc/actual-budget/env -> BUDGET_DOMAIN=...
- DNS: development-budgetapp.<domain>, test-budgetapp.<domain>, production-budgetapp.<domain>

Port conflicts
--------------
- actualctl instance set-port <instance> <new-port>
- nginx -t && systemctl reload nginx
- actualctl health <instance>

Version manifest
----------------
- If versions show "unknown" or mismatch across scripts:
  cat /usr/share/tkl-actual-bootstrap/VERSION
  sudo actualctl doctor --fix
  ./scripts/bootstrap.sh --version && actualctl --version
